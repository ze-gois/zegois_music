Rust + WebAssembly + Web Audio

Music

A tiny synthesized melody rendered from sine waves in Rust, played in the browser, and visualized on canvas.

What is happening?

  • Rust computes note frequencies with 440 * 2^(n / 12).
  • Rust renders mono f32 PCM samples for a small melody.
  • JavaScript copies those samples into a Web Audio AudioBuffer.
  • The same samples are drawn as a waveform on the canvas.
